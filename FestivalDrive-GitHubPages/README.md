# 節日車庫

可安裝到 iPhone 主畫面的網頁 App，含車機樣式預覽。GitHub Pages 只提供網頁託管，這個版本無法出現在 Kia Carnival 原廠 CarPlay。實車上的節日小工具需要原生 iOS App 與 WidgetKit 擴充套件。

## GitHub Pages 部署

1. 建立 GitHub 儲存庫，將解壓縮得到的所有檔案上傳至 `main` 分支根目錄，確保 `index.html` 直接位於根目錄。
2. 在儲存庫開啟 **Settings → Pages → Build and deployment**。
3. 選 **Deploy from a branch → main → /(root)**，按 **Save**。
4. 從 Pages 設定畫面取得網址，用 iPhone Safari 開啟。
5. 點分享 → **加入主畫面** → 開啟**以網頁 App 開啟** → 加入。

## 玩法

- 按「自動」依台灣日期套用主題，或選單一主題預覽。
- 萬聖節提前 4 天、聖誕節提前 7 天、元旦及農曆新年提前 3 天切換。聖誕節與元旦持續至隔天，農曆新年持續至初六。
- 生日使用你選的月日，每年當天顯示並優先套用。2 月 29 日在平年以 2 月 28 日顯示。
- 開啟頁面或回到前景時更新，也會在頁面開著時重新檢查日期。
- 第一次完整上線載入並完成網頁快取後，可離線開啟。主題與生日設定存在裝置瀏覽器內。
